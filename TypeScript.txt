1. 建立專案資料夾
mkdir ts-minimal
cd ts-minimal

2. 初始化專案
npm init -y

3. 安裝 TypeScript
npm install typescript -g
npm install typescript --save-dev

4. 初始化設定檔
npx tsc --init

5. 建立最小程式
index.ts

const message: string = "Hello TypeScript!";
console.log(message);

6. 編譯(包含監聽)
npx tsc -w

7. 執行
a. 從ts逕行編譯成js執行
npx ts-node index.ts

b. ts先編譯成js,再進行js指令執行
tsc index.ts
node index.js 

8. 延伸套件下載
npm install -D playwright typescript ts-node
npx playwright install

npx playwright codegen https://www.tw.coupang.com/
